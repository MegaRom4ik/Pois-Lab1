# ППОИС

Лабораторные работы на C++17.

## Лабораторная 1

Два варианта: вектор и крестики-нолики.

- `lab1/vector` — вектор в 3D: длина, сложение, вычитание, векторное произведение и другие операции.
- `lab1/tictactoe` — игра для двух игроков. Можно выбрать размер поля, сохранить и загрузить игру.
- `lab1/tests` — тесты.

## Запуск

Нужны Clang, Make и curl.

```sh
make all
./build/vector_cli
./build/tictactoe_cli
```

Проверить тесты:

```sh
make test
```

Вектор вводится так: `x1 y1 z1 x2 y2 z2`. В крестиках-ноликах первым ходит X, номера строк и столбцов начинаются с 1. Для победы нужно заполнить всю строку, столбец или диагональ.

Рабочая ветка — `Mega`.
